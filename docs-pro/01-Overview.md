# Docs Pro Overview

Docs Pro is a powerful Botble CMS plugin that provides a standalone documentation portal without depending on a public theme. It allows you to create, manage, and present technical documentation beautifully.

## Features

- **Standalone Portal**: Functions independently of your site's active theme.
- **Hierarchical Structure**: Supports deeply nested documents and categories.
- **Markdown Support**: Full support for standard Markdown formatting.
- **Import/Export**: Easily migrate documentation using ZIP packages.
- **Entomai License**: Secured with Entomai activation and private updaters.
