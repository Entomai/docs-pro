# Manging Documentation

Managing your documentation in Docs Pro is straightforward through the Admin Panel.

## Creating Categories and Documents

Docs Pro parses the filesystem structure (folder names and file names) to automatically build a hierarchical navigation tree when importing, or you can build it manually via the UI.

1. Navigate to **Docs Pro** in the sidebar.
2. Click **Create** to add a new document.
3. Use the hierarchical selector to place the document under a specific parent node.

## 3 Types of Nodes

1. **Title Nodes (Folders)**: Represents a grouping title in the sidebar. 
2. **Doc Nodes (Markdown Files)**: An actual readable documentation page. 
3. **Separator Nodes**: A visual separator line (`<hr>`) in the sidebar menu.
