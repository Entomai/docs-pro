# Import and Export

Docs Pro allows users to import full documentations directly from a ZIP file in the Admin panel.

## Import Workflow

When preparing documentation:
1. Generate the correctly prefixed folder and `.md` structure inside a `docs` or `docs-pro` directory.
   - Example `01-Overview.md`
   - Example `02-Admin/01-Settings.md`
2. Zip the contents of this folder into a `docs.zip` file (excluding the root folder wrapper).
3. In the Botble Admin Panel, go to **Docs Pro -> Import/Export**.
4. Upload your ZIP file to automatically regenerate the entire documentation tree.
